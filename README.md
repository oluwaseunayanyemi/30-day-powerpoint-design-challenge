The 30-Day PowerPoint Design Challenge is a practical curriculum designed to help presentation designers build real-world visual communication and storytelling skills.

Unlike generic design prompts that focus solely on visual aesthetics, this challenge focuses on communication problem-solving. Participants receive 30 authentic, raw client briefs spanning diverse industries—including technology, healthcare, finance, non-profits, architecture, and corporate executive leadership.

Each daily prompt presents realistic business content, core message requirements, key metrics, and human storytelling elements without prescribing layout or slide counts. Designers are challenged to interpret the content, structure the information hierarchy, and implement interactive PowerPoint capabilities (such as morph transitions, progressive disclosure, and click-to-reveal navigation) to turn static text into dynamic visual experiences.
